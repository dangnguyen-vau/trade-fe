# Layout Components

Thư mục này chứa các components định nghĩa cấu trúc bố cục của trang.

## Các components phổ biến

- TopBar: Thanh điều hướng phía trên
- Sidebar: Thanh điều hướng bên cạnh
- Footer: Phần cuối trang
- Container: Component bao bọc nội dung
- PageHeader: Tiêu đề trang

## Quy tắc thiết kế

1. Layout components nên có tính nhất quán giữa các trang
2. Tránh hardcode các elements bên trong, nên sử dụng props.children
3. Nên tách biệt logic và UI
4. Responsive design là ưu tiên hàng đầu
