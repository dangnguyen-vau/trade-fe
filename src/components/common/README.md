# Common Components

Thư mục này chứa các components cơ bản, có thể tái sử dụng trong toàn bộ ứng dụng.

## Các components phổ biến

- Button: Các nút bấm trong ứng dụng
- Card: Component hiển thị thông tin dạng card
- Input: Các trường nhập liệu
- Modal: Cửa sổ popup
- Dropdown: Menu dropdown
- LoadingSpinner: Hiệu ứng loading
- Badge: Hiển thị trạng thái
- Tooltip: Hiển thị thông tin khi hover

## Quy tắc thiết kế

1. Các common components nên đơn giản và tập trung vào một chức năng
2. Nên có đủ các props để tùy chỉnh nhưng không quá phức tạp
3. Styles nên được thiết kế để dễ dàng tùy chỉnh
4. Luôn tài liệu hóa các props của component bằng JSDoc và propTypes
