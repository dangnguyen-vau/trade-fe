# Styles

Thư mục này chứa các styles toàn cục cho ứng dụng.

## Các file chính

- **variables.css**: Các biến CSS (màu sắc, font, kích thước...)
- **global.css**: Styles toàn cục cho ứng dụng

## Quy tắc thiết kế

1. Nên sử dụng CSS variables để dễ dàng tùy chỉnh theme
2. Nên tổ chức các styles theo chức năng
3. Nên sử dụng BEM hoặc một phương pháp đặt tên CSS nhất quán
4. Tránh các styles quá cụ thể ảnh hưởng đến hiệu suất
