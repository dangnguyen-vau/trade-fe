# Constants

Thư mục này chứa các hằng số và cấu hình được sử dụng trong toàn bộ ứng dụng.

## Các file chính

- **colors.js**: Các màu sắc sử dụng trong ứng dụng
- **config.js**: Cấu hình ứng dụng
- **endpoints.js**: Các đường dẫn API
- **botStatus.js**: Enum cho trạng thái của bot
- **timeRanges.js**: Enum cho khoảng thời gian
- **routes.js**: Các đường dẫn trong ứng dụng

## Quy tắc thiết kế

1. Nên sử dụng uppercase cho các hằng số
2. Nên tài liệu hóa các hằng số bằng JSDoc
3. Nên tổ chức các hằng số theo chức năng
