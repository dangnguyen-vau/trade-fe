# Utils

Thư mục này chứa các hàm tiện ích được sử dụng trong toàn bộ ứng dụng.

## Các file chính

- **dateFormatter.js**: Các hàm định dạng ngày tháng
- **calculators.js**: Các hàm tính toán
- **formatters.js**: Các hàm định dạng dữ liệu

## Quy tắc thiết kế

1. Mỗi utility function nên là pure function
2. Nên tài liệu hóa các tham số và giá trị trả về bằng JSDoc
3. Nên viết unit tests cho các utility functions
4. Nên tổ chức các utility functions theo chức năng
