# Mocks

Thư mục này chứa các dữ liệu mẫu được sử dụng trong quá trình phát triển.

## Các file chính

- **botsData.js**: Dữ liệu mẫu về bots
- **randomBotsData.js**: Dữ liệu ngẫu nhiên về bots

## Lưu ý

Dữ liệu mẫu chỉ nên được sử dụng trong môi trường phát triển. Trong môi trường production, nên sử dụng dữ liệu thực từ API.
