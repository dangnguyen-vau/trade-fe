# Assets

Thư mục này chứa các tài nguyên tĩnh được sử dụng trong ứng dụng.

## Cấu trúc

- **images**: Chứa các hình ảnh, icons
- **fonts**: Chứa các font chữ

## Quy ước đặt tên

- Tên file nên viết theo kebab-case (VD: logo-main.png, icon-home.svg)
- Nên phân loại các assets theo chức năng hoặc tính năng
